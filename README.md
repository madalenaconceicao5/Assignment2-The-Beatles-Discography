# The Beatles Discography
A website dedicated to the discography of the band **"The Beatles".**

### Purpose
The goal of this website is to keep the users informed about the albums released by The Beatles. For each album, the website provides:
- **Title** of the album;
- **Release date**;
- **Total duration** of the album.

In addition, secondary pages offer a brief biography about each of the four members of the band:
- John Lennon
- Paul McCartney
- George Harrison
- Ringo Starr
